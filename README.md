# Muhammad Saad Khan — Portfolio

Static portfolio website (no build step).

```
portfolio/
  index.html
  css/style.css
  js/main.js
```

## Run locally
Open `index.html` in a browser. An internet connection is needed for the CDN-hosted Tailwind, three.js and Google Fonts.

## Deploy
Any static host, e.g. Cloudflare Pages: no build command, output directory `/`.
